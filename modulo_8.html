    Crea ed esegui il tuo primo Script Bash:

    1. Crea lo script con lo shebang: echo "#!/bin/bash" > saluto.sh
    2. Aggiungi il comando di stampa: echo "echo Benvenuti" >> saluto.sh
    3. Rendilo eseguibile: chmod +x saluto.sh
    4. Eseguilo usando il percorso relativo: ./saluto.sh
