Guida di riferimento per sysadmin, missioni di sicurezza e quiz sui permessi ottali.

1. Guida agli Scenari Sysadmin

Scenario: Nuovo Dipendente

Devi creare un utente, dargli una password e aggiungerlo al gruppo sviluppatori.

$ sudo useradd mario
$ sudo passwd mario
$ sudo groupadd dev
$ sudo usermod -aG dev mario

Scenario: Rilascio Web Server

Devi rendere visibile al mondo una cartella web, ma solo tu puoi modificarla.

# Proprietario: RWX, Altri: R-X
$ chmod 755 /var/www/html
# Proprietario: RW, Altri: R
$ chmod 644 /var/www/html/index.html

Scenario: Passaggio di Consegne

Un collega lascia l'azienda e devi trasferire tutta la sua cartella di progetto al nuovo utente 'admin'.

# -R cambia la proprietà ricorsivamente
# a tutti i file nella cartella
$ sudo chown -R admin:admin progetto/

2. Missioni sul Terminale Reale

Attenzione: per creare utenti sul tuo sistema WSL/VirtualMachine ti verrà richiesta la tua password (quella impostata in fase di installazione) a causa del comando `sudo`. Su Linux non vedrai gli asterischi mentre digiti la password!

Missione Alpha: Reclutamento

  • Assicurati di essere nella tua home directory.
  • Crea un nuovo utente chiamato ospite (ricorda di usare sudo).
  • Crea un gruppo chiamato visitatori.
  • Aggiungi l'utente ospite al gruppo visitatori.
  • Verifica la creazione lanciando il comando cat /etc/group e cerca 'visitatori' nelle ultime righe.

Missione Beta: La Cassaforte

  • Crea un file vuoto chiamato bilancio_segreto.txt.
  • Usa il comando ls -l per controllare i suoi permessi predefiniti (di solito 644).
  • Usa la notazione ottale per impostare i permessi a 600.
  • Lancia di nuovo ls -l per verificare: il file dovrebbe essere leggibile e scrivibile solo da te.
  • Usa il comando sudo chown root bilancio_segreto.txt per cedere la proprietà all'amministratore supremo.
