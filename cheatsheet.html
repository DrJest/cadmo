Linux Cheatsheet

I comandi essenziali da tenere sempre sottomano durante i laboratori.

man [comando]

La "Bibbia". Mostra il manuale ufficiale di qualsiasi comando. Premi q per uscire.

Navigazione (File System)

pwd

Print Working Directory. Ti dice in quale cartella ti trovi attualmente.

ls -la

Elenca il contenuto della cartella. -l formato lungo (dettagli), -a mostra i file nascosti.

cd /percorso

Change Directory. Cambia la cartella attuale.
cd .. sale di un livello. cd ~ va nella home.

mkdir nome_cartella

Crea una nuova directory (cartella).

Gestione File

touch file.txt

Crea un file vuoto o aggiorna la data di modifica di un file esistente.

cp orig.txt dest.txt

Copia file o directory. Usa -r per copiare intere cartelle.

mv file.txt /nuova/dir/

Sposta (o rinomina) file e directory.

rm file.txt

Rimuove (cancella) un file. Usa rm -rf per cartelle piene (ATTENZIONE: non si torna indietro!).

Lettura File

cat file.txt

Stampa l'intero contenuto del file sul terminale in un colpo solo.

less file.txt

Apre il file in un visualizzatore navigabile (frecce su/giù). Premi q per uscire.

head -n 10 file.txt

Mostra solo le prime 10 righe di un file.

tail -f /var/log/syslog

Mostra le ultime righe. L'opzione -f rimane in ascolto e mostra i nuovi aggiornamenti in tempo reale (utile per i log).

Ricerca & Pipe

grep "errore" file.log

Cerca la parola specificata all'interno del file testuale.

find /etc -name "*.conf"

Cerca all'interno della cartella /etc tutti i file che finiscono per .conf.

comando1 | comando2

Il carattere Pipe (|) prende l'output del primo comando e lo passa come input al secondo (es. ls -l | grep "txt").

> e >>

Reindirizzano l'output in un file. > sovrascrive il file, >> aggiunge alla fine (append).

Sicurezza & Permessi

sudo [comando]

SuperUser DO. Esegue il comando successivo con i privilegi massimi (amministratore/root).

chmod 755 file.sh

Modifica i permessi (Lettura, Scrittura, Esecuzione). 755 rende un file eseguibile per il proprietario.

chown utente:gruppo file

Cambia il proprietario (user) e il gruppo di un file o cartella.

passwd utente

Cambia la password di un utente specifico.

Sistema & Processi

htop (o top)

Task manager da terminale. Mostra CPU, RAM e i processi attivi in tempo reale.

ps aux

Genera un'istantanea statica di tutti i processi in esecuzione nel sistema e i loro PID.

kill -9 PID

Termina forzatamente un processo usando il suo Process ID (PID).

df -h

Mostra lo spazio su disco utilizzato e libero. -h lo rende leggibile (MB, GB).
