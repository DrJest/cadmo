Basi di Shell Scripting, variabili, costrutti condizionali e pianificazione dei task con Cron.

1. Guida Rapida: Scripting

Basi e Variabili

Ricorda sempre lo Shebang all'inizio e non mettere spazi attorno all'uguale (=).

#!/bin/bash
NOME="ITS Linux"
echo "Benvenuti in $NOME"

Costrutto IF

Prendi decisioni in base all'esistenza di un file o al valore di una variabile.

if [ -f file.txt ]; then
  echo "Il file esiste"
else
  echo "Non trovato"
fi

Ciclo FOR e Argomenti

Ripeti operazioni o leggi i dati passati allo script al momento del lancio ($1).

# Avvio: ./script.sh txt
for file in *.$1; do
  echo "Trovato: $file"
done

2. Missioni sul Terminale Reale

Usa l'editor nano (es. nano backup.sh) per scrivere il codice, salvalo con Ctrl+O ed esci con Ctrl+X.

Missione Alpha: L'Apprendista

  • Crea un file chiamato saluto.sh.
  • Scrivi all'interno lo shebang #!/bin/bash.
  • Chiedi il nome all'utente usando read NOME.
  • Stampa a video "Benvenuto nel server, $NOME!".
  • Salva il file, rendilo eseguibile (chmod +x) e lancialo con ./saluto.sh.

Missione Beta: Il Costrutto Logico

  • Crea uno script verifica.sh.
  • Usa un blocco if [ -f /var/log/syslog ]; then per controllare se il log di sistema esiste.
  • Se esiste, fagli stampare "Log trovato!". Aggiungi else per stampare "Errore critico" in caso contrario. Chiudi con fi.
  • Rendilo eseguibile e testalo.
