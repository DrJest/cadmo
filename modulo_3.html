Simulazione

    Metti in sicurezza il tuo script eseguendo i task in ordine:

    1. Crea uno script vuoto: touch script.sh
    2. Controlla i suoi permessi base (ls -l script.sh)
    3. Rendilo eseguibile usando l'ottale 755
    4. Verifica il cambiamento (ls -l script.sh)
    5. Usa i permessi di superutente per cederlo a root: sudo chown root script.sh
    6. Verifica il nuovo proprietario (ls -l script.sh)
