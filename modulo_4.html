    Crea la tua prima catena di montaggio dati:

    1. Crea un log usando la redirezione: echo "inizio" > log.txt
    2. Aggiungi un errore in coda (append): echo "errore" >> log.txt
    3. Leggi il contenuto per verificare: cat log.txt
    4. Usa il pipe per filtrare solo l'errore: cat log.txt | grep "errore"
    5. Trova il file appena creato: find . -name "*.txt"
