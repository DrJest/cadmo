Esercitazioni Modulo 2

Guida di riferimento, missioni pratiche da svolgere sul terminale e quiz di verifica finale.

1. Guida agli Scenari Comuni

Scenario: Nuovo Progetto

Devi creare una struttura di cartelle e file di partenza.

$ mkdir progetto_web
$ cd progetto_web
$ touch index.html style.css

Scenario: Ristrutturazione

Devi spostare o rinominare file esistenti.

# Rinomina file
$ mv vecchio.txt nuovo.txt
# Sposta in cartella padre
$ mv file.txt ..

Scenario: Pulizia Profonda

Eliminare dati in modo irreversibile. Assicurati SEMPRE di sapere dove sei (usa pwd) prima di lanciare questi comandi.

$ rm vecchio_log.txt
# Elimina cartella piena
$ rm -r cartella_vecchia/

2. Missioni sul Terminale

Apri il tuo terminale reale (WSL o Webminal) ed esegui queste operazioni. Non proseguire finché non hai completato ogni step.

Missione Alpha: L'Archivista

  • Torna alla tua home directory in modo assoluto.
  • Crea una cartella chiamata segreto.
  • Entra in segreto e crea un file nascosto chiamato .password.txt.
  • Torna indietro di un livello.
  • Lancia il comando per elencare i file in modo che il file .password.txt sia visibile da fuori.

Missione Beta: Distruzione Controllata

  • Crea una cartella chiamata da_cancellare.
  • Al suo interno crea tre file: 1.txt, 2.txt, 3.txt.
  • Copia il file 1.txt e chiamalo salvato.txt, spostandolo fuori dalla cartella.
  • Con un solo comando, elimina la cartella da_cancellare e tutto il suo contenuto.
