Speedrun Mode

15 Minuti di Fuoco

Risolvi questi 8 task nel minor tempo possibile. Usa la tua Home directory come area di gioco.

15:00
01. Crea tre file vuoti chiamati log1.txt, log2.txt e log3.txt usando un solo comando.
touch log1.txt log2.txt log3.txt
02. Copia il file log1.txt chiamando la copia backup_log.txt.
cp log1.txt backup_log.txt
03. Crea una cartella chiamata archivio che contenga al suo interno una cartella vecchi_log. Fallo con un comando solo (non due mkdir).
mkdir -p archivio/vecchi_log
04. Usa il carattere jolly asterisco (*) per spostare in un solo colpo tutti i file che finiscono in .txt dentro la cartella archivio/vecchi_log.
mv *.txt archivio/vecchi_log/
05. Elenca il contenuto della cartella archivio/vecchi_log mostrando i file nascosti e i dettagli completi (permessi, peso).
ls -la archivio/vecchi_log
06. Mostra a video solo le primissime 3 righe del file di sistema /etc/passwd.
head -n 3 /etc/passwd
07. Cancella senza pietà la cartella archivio e tutto ciò che vi è contenuto dentro.
rm -r archivio # o rm -rf archivio
08. Hai un vuoto di memoria: non ricordi a cosa serve l'opzione -p del comando mkdir. Apri il manuale di sistema per scoprirlo.
man mkdir # Ricorda di premere 'q' per uscire dal manuale!
root@its-lab:~# logout
