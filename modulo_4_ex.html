Guida di riferimento ai filtri, missioni pratiche sul terminale e quiz sulle redirezioni dei flussi.

1. Guida Rapida: Flussi e Filtri

Redirezione: Salvare l'Output

Salva il risultato di un comando in un file invece di stamparlo a schermo.

# > Sovrascrive il file
$ echo "Report" > file.txt
# >> Aggiunge alla fine (Append)
$ echo "Fine" >> file.txt

Grep: Trovare un ago nel pagliaio

Filtra enormi quantità di testo tenendo solo le righe che contengono la parola chiave.

# Cerca 'error' nel file syslog
$ grep "error" /var/log/syslog
# Ignora maiuscole/minuscole (-i)
$ grep -i "WARNING" log.txt

La Pipeline (|)

Passa l'output del primo comando come input del secondo comando. Puoi concatenare all'infinito!

# Elenca file -> Filtra solo i .conf -> Conta quante righe sono
$ ls -la /etc | grep ".conf" | wc -l

2. Missioni sul Terminale Reale

Apri il tuo terminale e componi le pipeline. Se rimani bloccato, rileggi la guida qui sopra!

Missione Alpha: Il Segugio di Log

  • Spostati nella directory dei log di sistema: cd /var/log
  • Elenca tutti i file presenti. Troverai un file chiamato auth.log, syslog o simile (scegline uno che contiene testo).
  • Usa il comando cat insieme al pipe | e a grep per trovare tutte le righe che contengono la parola root.
  • Evoluzione: Aggiungi un secondo pipe con wc -l per contare quante sono quelle righe, invece di stamparle a video.

Missione Beta: Il Costruttore di Liste

  • Torna nella tua home directory.
  • Elenca il contenuto della directory /etc e devia l'output usando > in un file chiamato lista_etc.txt.
  • Aggiungi in coda a questo stesso file l'elenco della directory /var usando >>.
  • Leggi il file lista_etc.txt usando less. Premendo 'q' potrai uscire.
