Missioni Lampo

Regola d'oro: Divieto assoluto di copia-incolla e divieto di usare il tasto backspace. Se sbagli a digitare, interrompi (Ctrl+C) e riscrivi da capo!

Missione 1: La Matrioska

Focus: Navigazione e percorsi

1. Partendo dalla tua home, crea tre cartelle annidate: livello1, entraci, crea livello2, entraci, crea livello3, entraci.

2. Controlla il tuo percorso per verificare di essere dentro livello3.

3. Crea un file vuoto chiamato tesoro.txt.

4. Con un solo comando, torna a livello1 (usando un percorso relativo).

$ mkdir livello1
$ cd livello1
$ mkdir livello2
$ cd livello2
$ mkdir livello3
$ cd livello3
$ pwd # Deve restituire .../livello1/livello2/livello3
$ touch tesoro.txt
$ cd ../..

Missione 2: Lo Stagista Disordinato

Focus: Spostare e Rinominare multipli

1. Nella tua home, crea questi 5 file insieme: img1.jpg, img2.jpg, testo.txt, appunti.txt, canzone.mp3.

2. Crea due cartelle: Immagini e Documenti.

3. Sposta le due immagini nella cartella Immagini in un colpo solo.

4. Sposta i due file di testo nella cartella Documenti.

5. Rinomina il file canzone.mp3 in rumore.mp3.

$ cd ~
$ touch img1.jpg img2.jpg testo.txt appunti.txt canzone.mp3
$ mkdir Immagini Documenti
$ mv img1.jpg img2.jpg Immagini/
$ mv testo.txt appunti.txt Documenti/
$ mv canzone.mp3 rumore.mp3

Missione 3: Paranoia Backup

Focus: Copie ricorsive

1. Crea una cartella chiamata configurazioni ed entraci.

2. Crea un file server.conf.

3. Esci dalla cartella tornando alla root del tuo progetto.

4. Fai una copia esatta dell'intera cartella configurazioni chiamandola configurazioni_backup.

5. Usa il comando per elencare i dettagli e verificare che esistano entrambe.

$ mkdir configurazioni
$ cd configurazioni
$ touch server.conf
$ cd ..
$ cp -r configurazioni configurazioni_backup
$ ls -l

Missione 4: Il Buco Nero

Focus: Rimozione attenta

1. Entra nella cartella configurazioni_backup creata nella missione precedente.

2. Cancella definitivamente il file server.conf.

3. Esci dalla cartella.

4. Distruggi l'intera cartella vuota configurazioni_backup.

$ cd configurazioni_backup
$ rm server.conf
$ cd ..
# Essendo ora vuota, puoi usare rmdir o rm -r
$ rm -r configurazioni_backup

Missione 5: L'Investigatore

Focus: Lettura log lunghi

1. Naviga in modo assoluto fino alla directory di sistema /var/log.

2. Usa il comando per elencare i file e individua un file di log (es. dpkg.log o syslog).

3. Prova a leggerlo tutto intero con il comando base di lettura. Scorrerà velocissimo.

4. Ora riaprilo con il comando di lettura a scorrimento interattivo, scorri in basso, poi premi 'q' per uscire.

5. Stampa a video solo le ultime righe per vedere l'evento più recente.

$ cd /var/log
$ ls
$ cat dpkg.log # o il nome del log che hai trovato
$ less dpkg.log # (usa le frecce, poi premi q)
$ tail dpkg.log
root@its-lab:~# exit
