Storage & Backup

Esercitazioni Modulo 7

Indagine sullo spazio libero, archiviazione dei dati e fondamenti per il montaggio dei dischi.

1. Guida Rapida: Storage

Analisi dello Spazio

Distinguere tra lo spazio globale e il peso di una specifica directory.

# Mostra spazio libero sui dischi
$ df -h
# Mostra quanto pesa la cartella attuale
$ du -sh .

Mount e Umount

Collegare fisicamente un disco hardware a una cartella di Linux.

# Monta la chiavetta (richiede root)
$ sudo mount /dev/sdb1 /mnt/usb
# Smonta la chiavetta (Rimozione sicura)
$ sudo umount /mnt/usb

Il coltellino svizzero: TAR

Raggruppa e comprimi i file per i backup. Ricorda i flag: c (crea), x (estrai), z (comprimi gzip), f (file).

# Comprimi la cartella 'dati'
$ tar -czf backup.tar.gz dati/
# Estrai l'archivio
$ tar -xzf backup.tar.gz

2. Missioni sul Terminale Reale

Apri il tuo terminale reale ed esegui i task sequenzialmente per prendere confidenza con l'archiviazione.

Missione Alpha: Esplorazione Spaziale

  • Usa il comando df -h per analizzare le partizioni del tuo server. Individua la partizione principale (solitamente montata su /) e segnati mentalmente quanto spazio libero le rimane.
  • Entra nella directory /var/log.
  • Lancia du -sh * per vedere quanto spazio occupa ogni singolo file e cartella in questa directory (il flag * applica il comando a tutto il contenuto).
  • Torna alla tua home directory (cd ~).

Missione Beta: L'Imballatore

  • Nella tua home, crea una directory chiamata progetto_importante.
  • Al suo interno crea due o tre file vuoti.
  • Usa tar -czf archivio.tar.gz progetto_importante per imballare e comprimere l'intera directory.
  • Verifica con ls -l che il file .tar.gz esista.
  • Metti alla prova il backup: elimina definitivamente la cartella originale con rm -r progetto_importante.
  • Rigenera la cartella estraendo l'archivio con tar -xzf archivio.tar.gz. Tutto è tornato come prima!
