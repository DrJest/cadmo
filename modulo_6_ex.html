Esercitazioni Modulo 6

Indirizzi IP, verifica connettività, download di file da riga di comando e installazione di pacchetti software.

1. Guida Rapida: Rete e Software

Diagnostica di Rete

Controlla il tuo IP locale e verifica se raggiungi internet.

# Trova il tuo indirizzo IP
$ ip a
# Testa connessione (usa Ctrl+C per fermare)
$ ping 8.8.8.8

Gestione Pacchetti (APT)

I comandi essenziali per installare programmi su Ubuntu/Debian (richiedono sudo).

# Aggiorna il catalogo software
$ sudo apt update
# Installa un programma
$ sudo apt install htop

Strumenti Web (wget e curl)

La riga di comando è il tuo browser. wget salva i file su disco, curl solitamente stampa l'output a schermo.

# Scarica un'immagine e la salva
$ wget https://sito.com/logo.png
# Mostra il codice HTML di una pagina web
$ curl localhost

2. Missioni sul Terminale Reale

Usa il tuo terminale reale per interagire con la rete. Esegui in sequenza i seguenti task.

Missione Alpha: Esplorazione Rete

  • Usa ip a per individuare il tuo indirizzo IP locale sulla rete eth0 o ens33.
  • Verifica se il server raggiunge internet lanciando ping -c 4 gnu.org (Il flag -c 4 dice di inviare solo 4 pacchetti e poi fermarsi).
  • Scarica la pagina principale di gnu.org usando il comando wget https://gnu.org. Questo creerà un file index.html nella tua cartella.
  • Verifica l'esistenza del file con ls -l e controlla le sue dimensioni.

Missione Beta: Il Tuo Primo Web Server

  • Aggiorna sempre l'elenco dei repository prima di installare qualcosa: sudo apt update
  • Installa il server web Nginx: sudo apt install nginx. Digita "Y" se chiede conferma.
  • Il server dovrebbe avviarsi da solo. Chiedi al server di rispondere a te stesso (localhost) usando curl localhost.
  • Se vedi a schermo il codice sorgente HTML con scritto "Welcome to nginx!", congratulazioni, hai appena ospitato il tuo primo sito web da terminale!
